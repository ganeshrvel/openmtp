# Installation

## System Requirements

- macOS 11.0 (Big Sur) or later (Kalam MTP kernel requires ≥ 11.0)
- Intel or Apple Silicon (arm64)
- An Android device with USB File Transfer support

## Download Options

### Homebrew Cask

```shell
brew install openmtp --cask
```

### GitHub Releases

Download the DMG for your architecture from [Releases](https://github.com/ganeshrvel/openmtp/releases):

- **[Apple Silicon](https://openmtp.ganeshrvel.com/?downloadApp=github&release=stable&platform=mac&arch=arm64)** — M1/M2/M3/M4 Macs
- **[Intel](https://openmtp.ganeshrvel.com/?downloadApp=github&release=stable&platform=mac&arch=x64)** — Intel Macs

## First Run

1. Open the DMG and drag OpenMTP to Applications.
2. Launch OpenMTP. macOS may prompt you to allow USB access — click **Allow**.
3. Connect your Android device via USB.
4. On your device: tap the "Charging via USB" notification → select **File Transfer**.
5. If prompted, grant "Allow access to device data" on your phone.
6. OpenMTP detects the device and shows both panes. You're ready to transfer files.
